# Dubai Heights House Competition

One link → animated house race → congratulations page.

## Weekly update
Edit `points.json` on GitHub (pencil icon), change the numbers and `label`, commit. Live in ~1 min.

## Logos
Put these in `assets/` (exact names):
`wolves.jpeg`, `gazelles.jpeg`, `falcons.jpeg`, `scorpions.jpeg`, `school-logo-white.png`
Missing logos fall back to a letter badge.

## Publish
Repo → Settings → Pages → Deploy from branch → `main` / root.
Link: `https://<username>.github.io/<repo>/`
